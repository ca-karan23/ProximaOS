# 🚀 ProximaOS™ v3.0.306.0 (Xiaomi 15 Ultra Edition) — Official Release

**Device**: Redmi Note 14 5G (`beryl` / `citrine`)  
**Base Firmware**: HyperOS 3 `OS3.0.306.0.WOQCNXM` (Android 16 | SDK 36)  
**Root Solution**: KernelSU-Next Pre-Integrated  
**Maintainer**: Karan  
**Build Size**: ~3.9 GB  

---

### 📋 Changelog (What's New)
- Added custom **ProximaOS™** boot animation & Setup Wizard (`Project ProximaOS` with Red-Orange `OS`).
- Added a new UI Package Installer with patched private app permissions (eliminated the 10-second MIUI danger pop-up).
- Implemented a new Power Menu style & iOS-style Volume Bar.
- Added a fully customizable **iOS-style Control Center** with premium blue tint and real-time glass blur everywhere.
- Upgraded **CPU & GPU Computility to Level 4** (`persist.sys.computility.cpulevel=4` & `gpulevel=4`) for flagship smoothness with zero border glitches.
- Implemented **iOS Emoji** support and iOS-style non-linear app opening/closing animations (`Parallel Sweep`).
- Enabled **120Hz Refresh Rate** across all applications out of the box.
- Included new screenshot frame designs, stackable widgets, expanded icon styles, and customized Themes/Security/App Vault.
- Unlocked **Always-On Display (AOD) "Always" mode** (removed 10s limit without SystemUI bootloops).
- Introduced **AI Dynamic & Depth Wallpapers**, plus new Game Turbo & Video Toolbox sidebar features (MEMC, SDR2HDR, Dolby Atmos, Hi-Fi Audio, Voice Changer).
- Resolved Camera lag + unlocked **Live Photos**, Focus Peaking, Object Tracking, and Gallery AI Eraser / Ultra HDR.
- Added a new **ColorOS-inspired About Phone** page with the bold **PROXIMAOS** metallic vector banner.
- Added My love 🥰.
